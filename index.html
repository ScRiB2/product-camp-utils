Приглашения C-level через Telegram — прототип

Вышла новая версия страницы. Вход в Telegram сохранится.
Загрузка…
1. Ключи приложения Telegram
Ключи — с my.telegram.org → API development tools. Хранятся только в этом браузере.
2. Вход в свой Telegram
В Telegram на телефоне: Настройки → Устройства → Подключить устройство → наведите камеру на код. Код обновляется сам.
3. Кандидаты
Шаблон приглашения
Подстановки: {имя} {фамилия} {компания} {должность} — кандидат, {волонтёр} — ваше имя из таблицы. **текст** станет жирным. Шаблон хранится в этом браузере; перед отправкой текст можно поправить для конкретного человека.
Ваши кандидаты, по которым пора что-то сделать: ответили вам, молчат после сообщения или давно «думают». Сроки можно поменять — они запоминаются в этом браузере и действуют только у вас.
Запрос подтверждения уходит от вашего имени через бота, с кнопками «Буду / Не смогу». Текст задан в боте и здесь не меняется — перед отправкой он показывается для проверки.
