Приглашения C-level через Telegram

Вышла новая версия страницы. Вход в Telegram сохранится.
Загрузка…
1. Ключи приложения Telegram
Ключи — с my.telegram.org → API development tools. Хранятся только в этом браузере.
2. Вход в свой Telegram
В Telegram на телефоне: Настройки → Устройства → Подключить устройство → наведите камеру на код. Код обновляется сам.
3. Кандидаты
Шаблон приглашения
Подстановки: {имя} {фамилия} {компания} {должность} — кандидат, {волонтёр} — ваше имя из таблицы. **текст** станет жирным, [текст](https://адрес) — ссылкой. Шаблон хранится в этом браузере; перед отправкой текст можно поправить для конкретного человека.
Ваши кандидаты, по которым пора что-то сделать: ответили вам, молчат после сообщения или давно «думают». Сроки можно поменять — они запоминаются в этом браузере и действуют только у вас.
Шаблоны напоминания
Обычное сообщение от вашего имени: напоминание о кэмпе с просьбой подтвердить участие. Подстановки и **жирный** — как в приглашении. [Яндекс Карты](https://адрес) — в сообщении будут слова «Яндекс Карты», по нажатию откроется адрес. Пока в тексте есть заглушка в квадратных скобках (например, [номер входа]), отправка заблокирована — впишите вместо неё настоящие данные. Человек отвечает словами: нажмите «Проверить чаты», прочитайте ответ и отметьте «Придёт» или «Не придёт».
